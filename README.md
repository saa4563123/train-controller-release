# 열차 운전대 제어기

직접 만든 운전대로 열차 시뮬레이터를 조작하는 윈도우 프로그램입니다.

아두이노는 가변저항 값과 스위치 상태만 계속 보내고, 단수 판정과 키 입력은 PC가 맡습니다.
그래서 가변저항 값이 틀어지거나 키 배치를 바꾸고 싶을 때
**아두이노를 다시 업로드할 필요가 없습니다.** 설정 창에서 고치고 저장하면 그만입니다.

원래는 제가 쓰려고 만든 건데, 운전대를 직접 만들어 보려는 분들이 계셔서 정리해 두었습니다.

## 내려받기

[Releases](../../releases)에서 `BveController.exe`를 받으세요.
설치 과정은 없습니다. 아무 폴더에나 두고 실행하면 됩니다.
윈도우에 기본으로 들어 있는 .NET Framework로 돌아갑니다.

## 처음 실행하면

프로그램을 켜면 화면에 이런 코드가 나옵니다.

```
BVE-XXXXX-XXXXX-XXXXX
```

이 코드를 저에게 보내주시면 라이선스를 만들어 드립니다.
받으신 라이선스를 인증 창에 붙여넣으면 바로 쓰실 수 있습니다.

라이선스는 컴퓨터 한 대에 묶입니다. 컴퓨터를 바꾸셨으면 새 코드를 알려주세요.
다시 만들어 드립니다.

## 만들 때 필요한 것

| 부품 | 용도 |
|---|---|
| Arduino Leonardo | ATmega32u4 계열이면 됩니다 |
| 가변저항 | 원핸들은 1개, 투핸들은 2개 |
| 스위치 3개 | 역전간 (전진 / 중립 / 후진) |
| 스위치 1개 | 데드맨 |

몸체는 3D 프린터로 뽑으셔도 되고, 나무나 아크릴로 만드셔도 됩니다.
배선도와 스케치는 프로그램 폴더의 `Arduino` 안에 들어 있습니다.

## 보정

가변저항은 제품마다 값이 다르고, 같은 제품이라도 조립하면 또 달라집니다.
그래서 처음 한 번은 보정을 해야 합니다.

`[노치 설정 / 보정]`에서 `[순서대로 전체 보정 시작]`을 누르고,
안내대로 핸들을 각 위치에 놓으면서 버튼을 누르면 됩니다. 몇 분이면 끝납니다.

보정한 값보다 조금 넓게 인식하도록 되어 있어서, 값이 다소 흔들려도 단수가 튀지 않습니다.

## 업데이트
