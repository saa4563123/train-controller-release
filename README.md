# TCOS — Train Controller Operation System

직접 만든 운전대로 열차 시뮬레이터를 조작하는 윈도우 프로그램입니다.

아두이노는 가변저항 값과 스위치 상태만 계속 보내고, 단수 판정과 키 입력은 PC가 맡습니다.
그래서 가변저항 값이 틀어지거나 키 배치를 바꾸고 싶을 때
**아두이노를 다시 업로드할 필요가 없습니다.** 설정 창에서 고치고 저장하면 그만입니다.

원래는 제가 쓰려고 만든 건데, 운전대를 직접 만들어 보려는 분들이 계셔서 정리해 두었습니다.

> **v2.8부터 이름이 TPOS에서 TCOS로 바뀌었습니다.**
> 계기판(Panel)이 아니라 운전대(Controller)라서 고쳤습니다. 기능은 그대로입니다.
> 쓰시던 라이선스는 **다시 받지 않으셔도 됩니다.**

## 내려받기

[Releases](../../releases)에서 세 파일을 받으세요.

| 파일 | 무엇 |
|---|---|
| `TCOS.exe` | PC 프로그램 |
| `config.ini` | 설정 (체험·업데이트 주소가 들어 있습니다) |
| `TCOS_Controller.ino` | 아두이노에 올릴 펌웨어 |

세 파일을 같은 폴더에 두고 `TCOS.exe` 를 실행하세요.

> 처음 실행하면 **15분 체험판**을 써 보실 수 있습니다(컴퓨터당 1회, 체험 중
> 인터넷 필요). 마음에 드시면 아래 메일로 기기 코드를 보내 라이선스를 받으세요.

설치 과정은 없습니다. exe는 아무 폴더에나 두고 실행하면 됩니다.
윈도우에 기본으로 들어 있는 .NET Framework로 돌아갑니다.

> 릴리스 아래에 GitHub이 자동으로 붙이는 `Source code (zip)`는
> **프로그램 소스가 아닙니다.** 이 저장소에 있는 안내 파일 두 개(README와 manifest)뿐입니다.
> 프로그램 소스는 공개하지 않습니다.

## 아두이노에 올리기

처음 한 번만 하면 됩니다.

1. 아두이노 IDE에서 `TCOS_Controller.ino`를 엽니다.
2. 보드를 **Arduino Leonardo**로 고릅니다.
3. 업로드합니다.
4. **시리얼 모니터를 닫습니다.** 열려 있으면 프로그램이 포트를 못 엽니다.

펌웨어는 가변저항 값과 스위치 상태만 PC로 보냅니다.
단수 판정과 키 입력은 PC가 하기 때문에, 가변저항 값이 틀어지거나
키 배치를 바꿔도 **아두이노를 다시 올릴 필요가 없습니다.**

옛 이름(`TPOS_Panel.ino`)으로 올려 두신 분은 **그대로 두셔도 됩니다.**
프로그램이 옛 펌웨어도 계속 인식합니다.

## 만들 때 필요한 것

| 부품 | 용도 |
|---|---|
| Arduino Leonardo | ATmega32u4 계열이면 됩니다 |
| 가변저항 | 원핸들은 1개, 투핸들은 2개 |
| 스위치 3개 | 역전간 (전진 / 중립 / 후진) |
| 스위치 1개 | 데드맨 |

몸체는 3D 프린터로 뽑으셔도 되고, 나무나 아크릴로 만드셔도 됩니다.

배선은 이렇습니다. 어느 핀을 쓸지는 프로그램에서 바꿀 수 있으니
다르게 다셨어도 됩니다.

| 핀 | 연결 |
|---|---|
| A0 | 주간제어기 가변저항 (투핸들이면 A1 에 제동 핸들 추가) |
| D7 / D8 / D9 | 역전간 전진 / 중립 / 후진 |
| D11 | 데드맨 |

스위치는 전부 `INPUT_PULLUP` 으로 잡혀 있어서 접점만 GND 로 떨어뜨리면 됩니다.

## 보정

가변저항은 제품마다 값이 다르고, 같은 제품이라도 조립하면 또 달라집니다.
그래서 처음 한 번은 보정을 해야 합니다.

`[노치 설정 / 보정]`에서 `[순서대로 전체 보정 시작]`을 누르고,
안내대로 핸들을 각 위치에 놓으면서 버튼을 누르면 됩니다. 몇 분이면 끝납니다.

보정한 값보다 조금 넓게 인식하도록 되어 있어서, 값이 다소 흔들려도 단수가 튀지 않습니다.

## 화면

창 크기는 마우스로 끌어서 조절할 수 있고, 다음에 켤 때 그 크기로 뜹니다.
