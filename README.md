# 열차 운전대 제어기

실물 운전대(주간제어기 · 역전간 · 데드맨)를 만들어 열차 시뮬레이터에 연결하는
윈도우용 프로그램입니다. 아두이노는 센서 값만 보내고, 판정과 키 입력은 PC
프로그램이 합니다.

가변저항 범위나 키 배치가 바뀌어도 **아두이노를 다시 업로드할 필요가 없습니다.**
프로그램 설정 창에서 고치고 저장하면 끝입니다.

## 받기

[Releases](../../releases) 에서 최신 `BveController.exe` 를 받으세요.

설치할 것은 없습니다. 윈도우에 이미 들어 있는 .NET Framework 로 동작합니다.

## 쓰려면

프로그램을 실행하면 **기기 코드**(`BVE-XXXXX-XXXXX-XXXXX`)가 나옵니다.
그 코드를 판매자에게 보내면 라이선스를 발급해 드립니다.
받은 라이선스를 인증 창에 붙여넣으면 바로 쓸 수 있습니다.

라이선스는 컴퓨터 한 대에 묶입니다. 컴퓨터를 바꾸셨다면 새 기기 코드로
다시 발급받으시면 됩니다.

## 업데이트

프로그램이 켜질 때 새 버전이 있는지 확인하고 물어봅니다.
[예]를 누르면 알아서 받아서 설치하고 다시 시작합니다. 설정은 그대로 유지됩니다.

## 필요한 것

- Arduino Leonardo (또는 ATmega32u4 계열)
- 가변저항 1개 (원핸들) 또는 2개 (투핸들)
- 역전간 스위치 3접점, 데드맨 스위치
- 운전대 몸체 — 3D 프린터로 뽑거나 직접 만드시면 됩니다
